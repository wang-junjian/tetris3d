# 验收标准 v1（2026-10-09）

针对本轮目标：AI 真正能玩（双引擎可用）、默认 200ms/步、商业级视觉、视角可读性。

## A. AI 可用性（逻辑级）
- A1 内置启发式引擎：模拟 300 个方块不顶出，存活 ≥ 300，最终 maxHeight ≤ 12，空洞 ≤ 10。
- A2 落点枚举：空板 T 方块候选数 30~40 之间（合理性）。
- A3 引擎切换：`setAiEngine('builtin'|'jev')` 均能产生有效 plan。

## B. AI 可用性（端到端，浏览器）
- B1 内置引擎：AI 模式自动落子 ≥ 15 块，分数 > 0。
- B2 Jev 引擎：AI Log 出现 `JEV ✓`（真实 API 决策，置信度可见）。
- B3 无 Key 时回退内置引擎且游戏不中断。

## C. 默认参数
- C1 AI 动作速度默认 200ms/步（loadSettings 默认值 + 新用户 localStorage 为空时的实际生效值）。

- B4 模式切换回归：人类开局硬降一块→切 AI→落子数持续增长→切回人类手动一块→再切 AI 仍增长。

## D. 视觉（截图人工审查 + 客观检查）
- D1 默认相机接近正视：水平偏角 ≤ 15°，俯仰角 ≤ 12°，井内格子清晰可辨。
- D2 深井为实心机柜（背板/侧板/底座/立柱），不再是"一个镂空的框"。
- D3 方块为圆角发光体素，投影轮廓清晰，能看清落点。
- D4 无控制台错误，构建通过。

## 方法
- `verifier/v1/logic-test.ts`：vite-node 运行 A1~A3。
- `verifier/v1/e2e.cjs`：playwright-core 驱动 chromium，覆盖 B1~B3 + C1（读取设置默认值），输出截图至 `verifier/runs/`。
- D 项由截图 + 控制台日志人工确认。
