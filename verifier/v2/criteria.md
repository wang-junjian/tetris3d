# 验收标准 v2（2026-10-09）

在 v1 基础上新增：移动端适配 + 帮助按钮。v1 全部用例需保持通过（回归）。

## M. 移动端（视口 390×844，iPhone 12 尺寸）
- M1 无横向滚动：scrollWidth ≤ innerWidth + 1。
- M2 画面中心不被 HUD 遮挡：游戏开始后，画布中心点 elementFromPoint 命中 canvas。
- M3 得分/行数/等级等关键数据在移动端顶部条可见（不依赖桌面侧栏）。
- M4 人类模式下出现触屏按钮，点「硬降」后落子数 +1。
- M5 NEXT/AI LOG 抽屉可打开并显示内容。
- M6 竖屏下相机自动拉远：整个机柜（含底座顶梁）在画面内。

## H. 帮助
- H1 顶栏有「帮助」按钮，点击打开帮助弹窗，含游戏介绍、键盘/触屏操作、AI 双引擎与 Key 配置说明。
- H2 弹窗可关闭，无控制台错误。
